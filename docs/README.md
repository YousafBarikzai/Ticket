# Documentation

| Folder | What it holds |
|---|---|
| [`architecture/`](architecture/README.md) | The software architecture of the platform: context, runtime topology, module model, data, eventing, API, security, tenancy, engines, AI, experience, operations, evolution, quality attributes, risks and Phase 1 readiness. |
| [`adr/`](adr/README.md) | Architecture Decision Records. One file per decision, numbered, never edited after acceptance (superseded instead). |

The source requirements are the **Modular IT Ticketing Platform — Build Specification v2.0** (September 2026). This documentation does not restate the specification; it references its identifiers (MOD-nn, MOD-nn-Ex, PH-n, ADR-nn, OD-nn) and defines *how* the platform is built to satisfy it.
